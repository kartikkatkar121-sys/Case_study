# Unit 1 – Algorithmic Strategies Case Studies

### 1. E-Commerce Product Sorting
- Strategy: Divide and Conquer
- Algorithm: Merge Sort
- Purpose: Sort products according to price
- Time Complexity: O(n log n)

### 2. Google Calendar Application
- Strategy: Greedy
- Algorithm: Activity Selection
- Purpose: Select maximum non-overlapping events
- Time Complexity: O(n log n)

## Run
```bash
python E-Commerce-Product-Sorting/merge_sort.py
python Google-Calendar-Greedy/activity_selection.py
```
