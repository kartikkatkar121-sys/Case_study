# Unit 2 – Social Network Adjacency Matrix

### Case Study
- Data Structure: 2D Array / Adjacency Matrix
- Technique: Sparse Matrix Representation
- Purpose: Represent friendship connections among users
- Direct connection check: O(1)
- Matrix Space: O(V²)
- Sparse representation: O(E)

`1` represents a connection and `0` represents no direct connection.

## Run
```bash
python adjacency_matrix.py
python sparse_matrix.py
```
