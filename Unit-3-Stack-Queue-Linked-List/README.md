# Unit 3 – Stack, Queue and Linked List

### Case Study
Implementation of Stack and Queue operations using Linked Lists.

### Stack
- Push, Pop, Peek
- LIFO principle
- Useful for Undo/Redo and expression processing

### Queue
- Enqueue, Dequeue
- FIFO principle
- Useful for task/request management

### Linked List
- Create, Traverse, Search, Insert, Delete, Sort and Concatenate
- Singly linked list implementation

### Complexity
- Stack Push/Pop: O(1)
- Queue Enqueue/Dequeue: O(1)
- Linked List Search: O(n)

## Run
```bash
python stack_linked_list.py
python queue_linked_list.py
```
